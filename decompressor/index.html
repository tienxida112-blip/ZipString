About this page

⚠️ Never run a loader you received from someone else without inspecting it here first. Paste the whole loader above and you'll see the exact source it would execute (in its minified form if the minifier was used — minification is lossy by design: comments, indentation and original local names are gone). Loaders made before 2026-11-17 still decode — the old payload format is auto-detected and flagged.
what the loader contains
payloadASCII85 text in a long-bracket string — your source, minified then LZ77+Huffman compressed
enginea tiny pure-Lua 5.1 decompressor (b85 → container → Huffman → LZ77) with a length + checksum guard, so a corrupted loader refuses to run instead of executing garbage
what runsexactly what you see decoded above — nothing else, no network, no obfuscation
ZipString is a vibecoded tool that helps you minify your Lua code — everything runs locally in your browser, nothing you paste is ever uploaded.
Plain static files, zero dependencies: this page plus src/decompressor.js, src/compressor.js, src/app.js and src/style.css — keep the folder structure and it works from disk or any static host.
