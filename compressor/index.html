About the format

pipeline specification (minifier + ideas borrowed from tar + gzip/deflate + LZMA)
stage 0 — minifierstacked passes on a token-preserving Lua/Luau lexer: ① strips comments and all unnecessary whitespace, ② shortens numbers (0.1→.1), ③ drops call parens (f("x")→f'x'), ④ renames locals/params/loop-vars to a,b,c… with full scope tracking (fields, globals, labels, Luau types and string-mentioned names are never touched). Keeps --! directives. Luau backtick/interpolated strings pass through verbatim — nothing inside them is rewritten. Lossy — comments and original names don't survive.
stage 1 — LZ77hash-chain matcher with lazy evaluation, deep chain search and an optimal parse (dynamic programming over real Huffman bit costs, for inputs up to 2 MiB): window 2 MiB, match lengths 3…65542
stage 2 — rep-distancesLZMA-style distance reuse: a match at either of the two previous distances costs no distance bits at all
stage 3 — entropycanonical Huffman per block — the encoder emits both 16 K and 64 K-token blockings and keeps whichever is smaller: 365-symbol literal/length/rep tree + 76-symbol distance tree, RLE-serialized code lengths, 15-bit limit
stage 4 — containertar-style header [tag:1][length:4][hash:4] + bitstream; tag 0 = stored fallback for incompressible data
stage 5 — ASCII85bytes → printable chars with a randomized 85-char alphabet (no ], so any long-bracket level is safe)
integritylength + h = h·1000003 + byte (mod 2³²) checksum, verified before anything compiles
loaderpure Lua 5.1-compatible single line — runs on Luau (Roblox + executors), Lua 5.1–5.4, LuaJIT; needs loadstring/load; returns your script's return values. On plain Roblox, enable ServerScriptService ▸ LoadStringEnabled (or use an executor).
⚠️ ZipString compresses, it does not obfuscate — the (minified) source is fully recoverable, and the randomization only varies what the output looks like. Never run a loader you received from someone else without inspecting it here first.
ZipString is a vibecoded tool that helps you minify your Lua code — everything runs locally in your browser, nothing you paste is ever uploaded.
Plain static files, zero dependencies: this page plus src/decompressor.js, src/compressor.js, src/app.js and src/style.css — keep the folder structure and it works from disk or any static host.
